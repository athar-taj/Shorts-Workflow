## Meme / Sticker Pack

Drop your meme **stickers** here to automatically overlay them in generated Shorts.

### Supported formats
- `.png`
- `.webp`
- `.jpg` / `.jpeg`

### How it works
- When rendering the final video, the pipeline will randomly pick **one** image from this folder
  and overlay it for a few seconds (by default \(2.0s → 5.5s\)).

### Tips
- Prefer **transparent PNG/WebP** stickers (looks more like Instagram/WhatsApp memes).
- Keep the meme readable on mobile (bold, high-contrast).
